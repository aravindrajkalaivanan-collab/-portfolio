# Data Analyst Personal Portfolio

A responsive personal portfolio built with HTML, CSS and JavaScript.

## Files
- `index.html` – page content and sections
- `style.css` – responsive white portfolio design
- `script.js` – mobile navigation and current year
- `assets/profile-placeholder.svg` – replace with your own profile photo

## Run locally
1. Open this folder in VS Code.
2. Open `index.html` in your browser, or use the VS Code Live Server extension.
3. Replace `Your Name`, email and social links with your own details.
4. Replace the GitHub project URL with your real repository URL.
5. Replace `assets/profile-placeholder.svg` with your own photo named `profile.jpg`, then update the image `src` in `index.html` to `assets/profile.jpg`.

## Publish with GitHub Pages
1. Create a public GitHub repository, for example `portfolio`.
2. Upload all files and the `assets` folder, keeping the same folder structure.
3. Open repository Settings → Pages.
4. Choose Deploy from a branch, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site.
